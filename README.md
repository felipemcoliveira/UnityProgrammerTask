# UnityProgrammerTask



![Game Preview](Images/GamePreview.png)



This project was developed as part of a hiring process. I built it in **48 hours**, with the main focus on implementing two systems: **Inventory** and **Save**.



Because of the short time frame, the game is only a small showcase of my skills rather than a complete playable experience. Several features are missing, such as:

- A health bar for the character.

- More complete gameplay elements.



The gameplay itself is minimal, serving mostly as a test environment for the inventory and save systems.
